## 🚀 Instalación local

```bash
# Clonar repositorio
git clone https://github.com/Winderiano/Portafolio.git

# Entrar al directorio
cd portafolio-react

# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev
```

## 🛠️ Build para producción

```bash
npm run build
```
